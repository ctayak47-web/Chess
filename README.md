# Chess Helper – Android Чит для шахмат

Это простое Android-приложение для шахмат с базовым ИИ, которое показывает лучший ход против компьютера (или может быть расширено для использования с веб-сайтом chess.com).

## Особенности

- **Игровой процесс с IA**
  - Полное начальное расположение фигур.
  - Ходы компьютера вычисляются с помощью простой программы вычисления очков.
  - Подсказки рисуют стрелки от коня до squares-цели (локальный ИИ).

- **Чистый минималистичный зеленый интерфейс**
  - Зеленый фон (`#2E7D32`), светло-зеленые поля доски.
  - Большой видимой доски, отображаемой с помощью настраиваемого `BoardView`.
  - Простое меню выбора режима, индикаторы статуса, сообщения о взятии фигуры.

- **Два режима игры**
  1. **Против компьютера** – ПК вычисляет следующий лучший ход.
  2. **Против друга** – Currently placeholder for human vs human (can be extended with touch input).

- **Удобные элементы управления**
  - **Play Vs Computer / Play Vs Friends** – начать соответствующую игру.
  - **Exit** – закрыть приложение.

## Как запускать

### Из исходного кода

```
# 1. Откройте проект в Android Studio
# 2. Соберите и запустите
```

### С помощью Linux-интерфейса командной строки Harness

```sh
# Перейдите в каталог проекта
# Соберите проект
./gradlew assembleDebug
# Установите его на устройство
adb install app/build/outputs/apk/debug/app-debug.apk
```

## Будущее расширение (предлагается)

- **Подключение к chess.com**
  - Когда пользователь входит в режим игры с ботом, приложение может подключиться к сайту chess.com через WebView или Chrome Custom Tabs и отправить запрос на оценку позиции с помощью API.
  - Результаты будут отображаться в `computerMoveText` и визуализироваться на доске (стрелка от коня к целевому square).
- **Поддержка жестов для мобильных устройств**
  - Использование `GestureDetector` или RawTouchEvent для управления белыми фигурами.
- **Анализ перетасовки и история ходов**
  - Отслеживайте список ходов и визуализируйте их в боковой панели.
